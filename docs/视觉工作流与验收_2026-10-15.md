# 视觉工作流与本地验收（2026-10-15）

本机 `npm test` **91/91** 通过，其中新增 9 条按钮驱动完整网页流程；检查 390、1024、1440 三种宽度。受控 HTTP/协议夹具验证工程与数据闭环，未执行真实云端视觉模型或临床效果实验。

## 从图片到视觉结果

1. 打开「数据集」，选择并上传 JPG、PNG 或 WebP。单张最多 20MB、4000 万像素；每批最多 50 张、100MB。服务器完整解码单帧图片，拒绝损坏、截断和伪造内容。
2. 在「视觉数据集与人工标注」选取 1—5 张图，添加题目。检查顺序并指定整体图、局部图或参考图。
3. 按题填写人工标签、完整性、可答性、来源与复核状态。先保存当前题目到草稿，再保存整个数据集新版本。只有明确人工来源、已复核且完整的标签参与准确性指标；模型建议和待复核记录只参与输出比较与合规检查。
4. 可编辑带版本的受控词表。冲突别名被拒绝，待审核映射不启用别名归一化；保存新版本不修改旧实验。
5. 点击「按当前模板新增视觉提示词」生成对应结构化输出策略，再新建实验并选择视觉模式、视觉数据集和声明支持图片的模型。温度和图片上限取明确配置，不能仅按服务商名称推断。真实调用在确认页分别勾选费用和图片出站授权；复跑重新列出供应商和冻结图片清单。
6. 结果页显示 Micro P/R/F1、Macro F1、Exact Match、JSON 合规、拒答与稳定性。没有资格或零分母显示不可计算。稳定性以冻结模型×提示词×案例×重复矩阵检查，缺失、重复和无效输出不能制造 100% 稳定性。
7. 按模型、提示词、难度、分类、标注资格筛选案例，查看原图大图、输出和 TP/FP/FN。人工分类与说明单独保存，自动结果保留。可导出当前筛选 JSON，完整导出保留整场分母。

候选鉴别诊断模板使用独立字段与合规校验，不计算皮损标签 F1；没有可靠参考时不生成诊断准确率。拒答较多本身也不代表更安全。

## 图片归属、删除和迁移

所有图片读取、元信息、删除、恢复、数据集引用、freeze 和 replay 都校验当前会话。相同 SHA 内容可共享底层文件，但每个会话拥有独立访问记录。删除只归档当前访问权，不移动其他会话的文件；被数据集或冻结实验引用的图片不能删除。回收站可恢复本会话的记录。历史无归属图片只允许本机原会话显式认领，不能借认领窃取其他会话图片。

「本机 ZIP 迁移」仅导出勾选资源；原图默认不勾选。包包含选择的数据、标注、词表、提示词与图片 SHA 清单，不包含模型凭证或 grant。导入先校验并预览新 ID 映射，再提交为新资源，不覆盖原数据或实验。拒绝路径穿越、绝对路径、符号链接、重复条目、过度压缩、CRC 与哈希错误。元数据包只能引用当前会话已经拥有的图片。

默认 JSON、CSV、Markdown、配置和原始结果导出不包含图片 Base64；原始执行配置仍保留在本机受控运行目录用于复现。CSV 与 Markdown 均按冻结标注和词表计算，并包含最新人工说明。不要把导出中的 Mock 分数当成真实模型能力。

## 测试与运行

```bash
npm test
npm run test:unit
npm run test:browser
```

默认入口预加载隔离目录、凭证清理和网络阻断；子 worker 继承外网保护。浏览器测试使用合成图和独立会话，实际点击上传、建题、运行、复核、导出、复跑、取消和 ZIP。CI 已补充 Chromium 安装步骤，但本轮未推送或执行新的远端 CI。

正式服务仍通过 `启动.cmd` 启动。占用端口时先核对健康端点的应用身份，未知服务不会被当作本项目打开。服务重启后网页密钥需重新补充；本机环境凭证只允许原会话使用。两项目数据库、会话和凭证相互独立，通过限时 grant 协作。
