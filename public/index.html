METHOD & CONNECTIVITY
先辨清证据，再解释分数。
三种评价，分别记录
规则评价：Promptfoo contains、is-json 等原生断言，JSON任务额外约束字段。
参考答案评价：人工事实词覆盖率，逐项保存命中依据。可能漏判同义表达或误判否定，不叫语义准确率。
LLM Judge：可选原生 llm-rubric，固定模型版本、rubric与温度0；调用和重试计入总预算。评审也有偏差，需人工复核。
稳定性是重复输出众数占比，不代表正确。综合排名权重是你的偏好；缺失启用维度时不排名。
实时模型接入
打开「模型管理」，选择服务商与协议，填写账号可用的 Model ID、HTTPS 地址和密钥，然后保存并测试连接。
回到实验页面，多选已配置模型，确认本次费用后开始评测。模型版本、参数和价格冻结在实验中；密钥仅由后端保存，服务重启后需补充。
保留本项目 .env 的 Kimi / Qwen 兼容配置。网页模型无需修改 .env。自定义地址须由你确认可信，不允许访问服务器内网。
AgentLab 公平对照
先在 AgentLab 中对指定模型创建评测授权，再将配置 ID 和令牌填入本工作台的「模型管理」。两个项目的密钥分别管理。
连接成功后，同一模型的 Single / Multi 选项进入评测矩阵。比较使用相同题目、提示词、参数、搜索条件和每题预算。
Mock 对照只检验接口与流水线。真实比较需人工核验事实与引用；内部调用预算与平台外层请求预算分别记录。
复现与恢复
每次运行保存原始 Promptfoo 结果、完整非敏感配置、数据与提示词 SHA256、原始输出及调用记录。缓存关闭。
取消或重启会保留已完成单元。复跑从冻结数据创建新实验；原记录不会被覆盖，实时模型需可用凭证与当次费用确认。
JSON / CSV / Markdown 导出均包含当前人工标注；本机 data/runs 保存审计包。Token 或价格缺失时显示未知。
